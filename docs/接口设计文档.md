# 明月图书借阅管理系统 V1.0 接口设计文档

## 1. 文档概述

### 1.1 文档目的

本文档基于《PRD 产品需求文档》《系统概要设计说明书》和《数据库设计说明书》编写，用于定义明月图书借阅管理系统 V1.0 的后端接口范围、接口规范、权限要求、请求参数、响应结构和主要业务错误码。

本文档作为前后端联调、后端开发、接口测试和验收测试的依据。

### 1.2 设计范围

接口覆盖以下模块：

1. 登录认证。
2. 用户管理。
3. 角色权限管理。
4. 系统配置。
5. 图书分类。
6. 图书资料。
7. 馆藏副本。
8. 借阅管理。
9. 归还管理。
10. 逾期罚款。
11. 统计查询。
12. 读者个人中心。

## 2. 接口通用规范

### 2.1 基础路径

系统接口统一使用以下基础路径：

```text
/api/v1
```

示例：

```text
POST /api/v1/auth/login
GET  /api/v1/books
```

### 2.2 请求格式

1. 请求数据格式使用 JSON。
2. 请求头 `Content-Type` 为 `application/json`。
3. 除登录接口和公开图书查询接口外，其他接口应携带登录凭证。

### 2.3 认证头

```http
Authorization: Bearer <access_token>
```

### 2.4 统一响应结构

```json
{
  "code": 200,
  "message": "success",
  "data": {}
}
```

字段说明：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `code` | Integer | 业务状态码 |
| `message` | String | 响应提示 |
| `data` | Object | 业务数据 |

### 2.5 分页响应结构

```json
{
  "code": 200,
  "message": "success",
  "data": {
    "pageNo": 1,
    "pageSize": 10,
    "total": 125,
    "items": []
  }
}
```

分页参数说明：

| 参数 | 类型 | 必填 | 默认值 | 说明 |
| --- | --- | --- | --- | --- |
| `pageNo` | Integer | 否 | 1 | 当前页码 |
| `pageSize` | Integer | 否 | 10 | 每页数量 |

### 2.6 时间格式

时间字段统一使用：

```text
yyyy-MM-dd HH:mm:ss
```

日期字段统一使用：

```text
yyyy-MM-dd
```

## 3. 状态码设计

| 状态码 | 说明 |
| --- | --- |
| 200 | 成功 |
| 400 | 请求参数错误 |
| 401 | 未登录或登录凭证无效 |
| 403 | 无权限访问 |
| 404 | 数据不存在 |
| 409 | 数据冲突或状态冲突 |
| 422 | 业务规则校验失败 |
| 500 | 系统内部错误 |

## 4. 角色权限约定

| 角色编码 | 角色名称 | 说明 |
| --- | --- | --- |
| `admin` | 超级管理员 | 拥有全部接口权限 |
| `librarian` | 图书管理员 | 拥有图书、馆藏、借阅、归还、罚款、统计相关权限 |
| `reader` | 普通读者 | 拥有图书查询、个人资料、本人借阅和本人罚款查询权限 |

权限说明：

1. `admin` 可访问全部接口。
2. `librarian` 不可维护用户角色权限，但可维护图书业务数据。
3. `reader` 只能访问公开查询和本人数据。
4. 读者端接口涉及用户 ID 时，以登录凭证中的当前用户为准，不信任前端传入的用户 ID。

## 5. 认证接口

### 5.1 用户登录

```http
POST /api/v1/auth/login
```

权限：未登录可访问。

请求参数：

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `username` | String | 是 | 用户名 |
| `password` | String | 是 | 密码 |

请求示例：

```json
{
  "username": "admin",
  "password": "123456"
}
```

响应数据：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `accessToken` | String | 访问令牌 |
| `tokenType` | String | 令牌类型，固定为 `Bearer` |
| `expiresIn` | Integer | 有效期，单位秒 |
| `userInfo` | Object | 当前用户基础信息 |
| `permissions` | Array | 当前用户权限编码 |

### 5.2 退出登录

```http
POST /api/v1/auth/logout
```

权限：登录用户。

响应数据：空对象。

### 5.3 获取当前用户

```http
GET /api/v1/auth/me
```

权限：登录用户。

响应数据：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `id` | Long | 用户 ID |
| `username` | String | 用户名 |
| `realName` | String | 真实姓名 |
| `roles` | Array | 角色编码 |
| `permissions` | Array | 权限编码 |

## 13. 归还接口

### 13.1 办理归还

```http

```

权限：`admin`、`librarian`。

请求参数：

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `borrowId` | Long | 是 | 借阅记录 ID |
| `copyStatus` | Integer | 否 | 归还后副本状态，默认可借 |
| `returnTime` | String | 否 | 归还时间，不传默认当前时间 |
| `remark` | String | 否 | 备注 |

响应数据：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `borrowId` | Long | 借阅记录 ID |
| `status` | Integer | 借阅状态 |

| `fineId` | Long | 罚款记录 ID |
| `fineAmount` | Decimal | 罚款金额 |

业务规则：

1. 已归还记录不能重复归还。
2. 归还时更新借阅记录和副本状态。
3. 逾期归还时生成或更新罚款记录。

## 18. 主要业务错误码

| 错误码 | HTTP 状态 | 说明 |
| --- | --- | --- |
| `AUTH_INVALID_CREDENTIALS` | 401 | 用户名或密码错误 |
| `AUTH_DISABLED_USER` | 403 | 用户已禁用 |
| `AUTH_TOKEN_INVALID` | 401 | 登录凭证无效 |
| `PERMISSION_DENIED` | 403 | 无权限访问 |
| `USER_USERNAME_EXISTS` | 409 | 用户名已存在 |
| `USER_READER_NO_EXISTS` | 409 | 读者编号已存在 |
| `ROLE_CODE_EXISTS` | 409 | 角色编码已存在 |
| `PERMISSION_CODE_EXISTS` | 409 | 权限编码已存在 |
| `CATEGORY_CODE_EXISTS` | 409 | 分类编码已存在 |
| `CATEGORY_IN_USE` | 422 | 分类已被图书使用 |
| `BOOK_ISBN_EXISTS` | 409 | ISBN 已存在 |
| `BOOK_NOT_ON_SHELF` | 422 | 图书未上架 |
| `BOOK_HAS_UNRETURNED_COPY` | 422 | 图书存在未归还副本 |
| `COPY_CODE_EXISTS` | 409 | 馆藏编号已存在 |
| `COPY_NOT_AVAILABLE` | 422 | 馆藏副本不可借 |
| `BORROW_LIMIT_EXCEEDED` | 422 | 超过最大借阅数量 |
| `BORROW_DUPLICATED_BOOK` | 422 | 同一图书存在未归还记录 |
| `BORROW_RECORD_NOT_RETURNABLE` | 422 | 借阅记录不可归还 |
| `FINE_ALREADY_PAID` | 422 | 罚款已处理 |

## 19. 接口设计结论

本接口设计以图书资料、馆藏副本、借阅记录和罚款记录为核心资源，采用 REST 风格组织接口路径。接口权限围绕超级管理员、图书管理员和普通读者三类角色设计，支持管理端和读者端的核心业务闭环。后续详细开发时，可在本文档基础上进一步补充字段校验规则、OpenAPI 描述和接口测试用例。
