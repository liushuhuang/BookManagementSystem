# BookManagementSystem
明月图书借阅管理系统 V1.0（BMS）

## MVP Demo

1. Initialize MySQL with `src/main/resources/db/schema.sql`.
2. Optional repeatable seed script: `src/main/resources/db/demo-data.sql`.
3. Start the backend with `mvn spring-boot:run`.
4. Open `http://localhost:8080/`.
5. Login with `librarian_test / 123456`.
